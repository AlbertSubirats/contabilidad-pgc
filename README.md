# Ayuda Contabilidad

Una web para estudiar contabilidad con el Plan General de Contabilidad (PGC):

- **Buscador de cuentas**: la ficha de cada cuenta, con su definición y su
  movimiento (qué se carga y qué se abona).
- **Simulador**: practicar ejercicios con el libro diario, el mayor, el balance
  de sumas y saldos y las cuentas anuales.
- **Wiki del articulado**: el Marco Conceptual y las normas de registro y
  valoración.

Está en construcción. El plan está en [docs/hoja-de-ruta.md](docs/hoja-de-ruta.md)
y el historial de decisiones en [CHANGELOG.md](CHANGELOG.md).

El contenido contable sale del texto refundido del PGC (versión 2021), que está en
[sources/](sources/).
